# Grand Strategy — Browser Prototype

A mobile-friendly, single-player logistics-first strategy prototype. Runs locally in a browser; no install, account, server, or external libraries required.

## Play
Open `index.html` in a modern browser. On GitHub, upload the contents of this folder to a repository and enable GitHub Pages.

## Current mechanics
- 10×10 tile map with three powers
- Player-controlled and AI turns
- Gold/steel income, mines, factories, railways, ports, mountains and forests
- Recruitment, adjacent movement, attacks and territory capture
- Capital-loss defeat and regional victory conditions
- Local browser save

## Prototype notes
This is a playable first implementation, not yet a complete digital transcription of the entire tabletop rulebook. Some combat, terrain and economic values are simplified for the initial AI skirmish. The game is entirely client-side; saves are local to the browser/device.
